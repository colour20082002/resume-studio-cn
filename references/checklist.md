# 交付前检查清单

## 内容
- [ ] 姓名、手机、邮箱、城市、到岗时间都是真实信息，没有【待填】。
- [ ] `summary` 一段 80–140 字，含年限、优势、带数字的成果、求职方向。
- [ ] 每条 bullet 有动词、有结果；有数字的写了数字。
- [ ] 核心能力 4–6 条，每条都能在经历里找到证据。
- [ ] 时间倒序，时间格式统一 `YYYY.MM – YYYY.MM`，无空档或未解释的断档。
- [ ] 证书只列真实持有的。
- [ ] 没有第一人称、没有「负责…工作」这类空话、没有公司简介。

## 匹配度
- [ ] 求职意向与目标 JD 的岗位名称一致。
- [ ] 与 JD 最相关的 3 条能力排在前三。
- [ ] 每段经历的 bullets 已按 JD 优先级重排，最贴近的放第一条。
- [ ] `check.py --keywords` 里填的 JD 关键词全部命中。

## 版面
- [ ] PDF 页数符合 `resume.yml` 的 `pages` 配置（默认 1 页，按需设 2），没有出现空白第三页。
- [ ] 第二页顶部不是孤立的章节标题。
- [ ] 若为 2 页，两页内容量基本均衡，第二页留白不超过 3–4 行。
- [ ] 日期右对齐、公司名左对齐；三处「主要职责：」标签写法一致。
- [ ] 照片按要求显示或隐藏；隐藏后版面没有空洞。
- [ ] 中文与英文/数字之间有半角空格。

## 输出
- [ ] `py -3 scripts/check.py --root <目录> --pages 2` 结果为 PASS。
- [ ] PDF 打开后字体正常，没有方块字或字体回退。
- [ ] Word 版与 PDF 内容一致（若同时交付）。
