# 内容写作规则

适用于 `resume.yml` 的所有文字字段。目标是让每条内容都能被面试官追问并站得住。

## 自我概述 summary
- 80–140 字，一段话，不分行。
- 结构：年限与行业 → 核心优势（可验证） → 代表性成果（带数字） → 求职方向。
- 只写简历后面出现的事实，不写简历里没有的能力。
- 不写「学习能力强」「抗压能力强」这类无法验证的形容词，除非紧跟一个事实。

## 工作经历 bullets
- 每条 20–50 字，一条只讲一件事。
- 句式：动词开头 + 做什么 + 怎么做 + 结果。例：主导逾期账户催收，建立分级提醒机制，推动营业部坏账率下降 4% 以上。
- 有数字必须写数字：人数、金额、百分比、周期、数量、满意度。
- `label` 用 2–6 字概括这条职责，整份简历内不重复。
- 时间倒序，最近的在最前；每段 3–6 条，最近一段可多，早期一段 1–2 条。
- 不用第一人称「我」，不写「负责…工作」这种没有信息量的开头。

## 核心能力 competencies
- 4–6 条，`label` 是能力名（2–4 字），`text` 是用「 · 」分隔的关键词串，4–6 个词。
- 关键词必须能在工作经历里找到对应证据。

## 教育与证书
- `education.detail` 一句话，写主修课程或在校成果，不写空泛评价。
- 证书只列真实持有，写全称或通用缩写。

## 中文排版
- 中文与英文、数字之间加半角空格：`Excel 数据透视`、`5 项行业荣誉`。
- 日期统一 `YYYY.MM – YYYY.MM`，连接号用 `–`。
- 百分比统一 `4%`，范围用 `–`。
- 全角标点用于中文句子，句末不加句号（条目式）。
- 不混用「·」与「/」：关键词之间用 ` · `，岗位与行业之间用 ` / `。

## 禁止项
- 编造公司、职位、时间、数字、证书。
- 同一段经历里重复同一条职责。
- 把岗位职责原样抄成公司简介（「公司成立于…」）。
- 超过三行的大段文字。
